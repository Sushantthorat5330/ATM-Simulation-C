# ATM Simulation System in C

## Project Overview

This project is a console-based ATM Simulation System developed using C programming.

The project simulates basic ATM operations such as PIN verification, balance checking, money deposit, money withdrawal, and exiting the application.

## Features

- PIN verification
- Login authentication
- Check account balance
- Deposit money
- Withdraw money
- Balance validation
- Invalid amount handling
- Insufficient balance checking
- Menu-driven interface
- Exit option

## Program Flow

1. The program starts.
2. The user enters a PIN.
3. The entered PIN is verified.
4. If the PIN is incorrect, the program terminates.
5. If the PIN is correct, the ATM menu is displayed.
6. The user can:
   - Check balance
   - Deposit money
   - Withdraw money
   - Exit
7. The menu continues until the user selects Exit.

## ATM Operations

### 1. Check Balance

Displays the current account balance.

### 2. Deposit Money

The user enters a deposit amount. The amount is added to the current balance if it is valid.

### 3. Withdraw Money

The user enters a withdrawal amount.

The program checks:

- Whether the amount is valid
- Whether sufficient balance is available

If the conditions are satisfied, the amount is deducted from the balance.

### 4. Exit

The program terminates after displaying a thank-you message.
